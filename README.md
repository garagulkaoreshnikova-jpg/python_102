# Атлас погоды

Небольшое приложение на Flask: ищет город, показывает текущую погоду и прогноз на ближайшие часы. Пейзаж меняется вместе с погодой: для дождя и снега используются отдельные картины, для снега и дождя поверх них идёт лёгкая анимация.

## Запуск

Из папки `python_102` активируйте окружение, установите Flask и запустите сервер:

```bash
source env/bin/activate
pip install -r requirements.txt
python3 app.py
```

Затем откройте в браузере <http://127.0.0.1:5050>.

Прогноз загружается из Open-Meteo при наличии подключения к интернету. API-ключ не нужен.
